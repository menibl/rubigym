# סריקת הגעה למועדון

כפתור הסריקה בראש דף הבית פותח את מסך הכניסה ומבקש מיד הרשאת מצלמה. קוד ה־QR המודפס הקיים במועדון נשאר תקף. מפענח QR מקומי מאפשר סריקה גם ללא BarcodeDetector; תמונות המצלמה אינן נשלחות לשרת. מצלמה דורשת HTTPS והרשאת הדפדפן. בסגירה, יציאה מהמסך או מעבר לרקע המצלמה נעצרת.

לאחר סריקה מוצגות האפשרויות הזמינות כעת ביומן, בהתאם למנוי, תשלום, תוקף והצהרת בריאות. ניתן להירשם גם ללא הרשמה מראש:

- Open Gym: הרשמה למשבצת פעילה ותיעוד הגעה, ללא חיוב או ניכוי נוסף. נשמרים מגבלת שתי הרשמות ביום, תפוסה ואיסור חפיפה.
- אישי/זוגי: החל מ־30 דקות לפני האימון ועד סיומו, רק אימון פנוי או הרשמה קיימת. הרשמה חדשה מנכה קרדיט אחד מהכרטיסייה המתאימה. זוגי מחייב בחירת בן משפחה תקין ורושם את שני המשתתפים; רק כרטיסיית המשלם מנוכה.
- הרשמה קיימת: תיעוד הגעה בלבד, ללא ניכוי נוסף, גם אם היתרה כבר אפס.
- קבוצתי: נשמר אישור ההגעה לאימון שנרשם מראש; סריקה אינה עוקפת רישום קבוצתי.

בחירה מוצגת כשיש כמה אפשרויות. אפשרות יחידה ללא צורך בבן זוג מאושרת אוטומטית. אין אפשרות ליצור אימון שלא קיים ביומן, לעקוף אימון מלא או לבחור מנוי שאינו בתוקף. אם אין בן משפחה מתאים לזוגי יש לפנות למאמן.

`GET /api/attendance/arrival` מחשב אפשרויות מתוך מצב השרת. `POST` מבצע הרשמה, ניכוי ותיעוד יחד בשמירת מצב אחת עם בדיקת גרסה וניסיון חוזר במקרה של התנגשות. מזהה הגעה קבוע למתאמן/משבצת/תאריך מונע חיוב נוסף בסריקה חוזרת או בניסיון חוזר לאחר כשל רשת. זהות המתאמן נלקחת מהסשן ולא מהבקשה. אין שינוי סכמת מסד הנתונים. אותו מנגנון משמש בנתוני הדמו המבודדים של Pages.

בדיקות: `node --test server/club-check-in.test.js server/personal-booking.test.js`, וכן `pnpm run lint` ו־`pnpm run build`. לאחר פריסה ל־staging יש לבדוק במכשיר אמיתי הרשאת מצלמה, סריקת הקוד המודפס, בחירת סוג אימון, ניכוי יחיד, סריקה חוזרת ופתיחת עריכת תמונת הפרופיל מדף הבית.
